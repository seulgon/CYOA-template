# CYOA-template (쵸아 제작 템플릿)

이 레포지토리는 나만의 **CYOA (Choose Your Own Adventure)** 게임을 쉽고 세련되게 제작할 수 있도록 뼈대와 핵심 UI 기능만 남겨둔 React + TypeScript + Vite 기반의 템플릿입니다.

모바일 및 데스크톱 환경 모두에 호환되는 반응형 레이아웃, 동적 포인트/스탯 계산 시스템, 유려한 비주얼 노벨식 컷씬 모듈을 내장하고 있습니다.

---

## 주요 기능 (Features)

1. **인터랙티브 컷씬 시스템 (Story Screen)**
   - 비주얼 노벨 형식의 스토리 연출 지원.
   - 대사 길이에 맞춰 대화 상자 크기가 유동적으로 변하는 **가변형 대화 상자** (`height: auto`).
   - 대화창 본문 스크롤 시 대사 넘김 버그 방지 및 배경 클릭 시 정상 진행을 조율하는 **이벤트 투과(Pointer events) 처리**.
   - 대사 완성 후 선택지 버튼이 뾰로롱 나타나는 **딜레이 최적화** (기존 `0.6초` $\rightarrow$ `0.2초`로 단축).

2. **동적 빌더 시스템 (CYOA Builder)**
   - **단일 선택(Single-select)** 및 **다중 선택(Multi-select)** 카드 UI 제공.
   - 카드를 선택할 때마다 실시간으로 포인트 차감 및 캐릭터 스탯 가산/차감.
   - 특정 카드 획득 시 보너스 획득 알림(Toast) 제공.

3. **최종 빌드 요약 (Character Sheet)**
   - 플레이어가 설정한 이름, 선택한 테마, 스탯, 획득 태그 및 아이템/장비를 깔끔한 시트 형태로 요약.
   - 캐릭터 빌드 데이터 **JSON 파일 저장(Export) 및 불러오기(Import)** 기능 제공.

4. **오디오 시스템 (BGM & SFX)**
   - 단계별 BGM 전환 및 음량 설정이 가능한 플레이어 모달 탑재.

## 시작하기 (Getting Started)

개발이나 깃허브(GitHub)가 완전히 처음이신 초보자분들도 아래의 단계를 따라 하시면 쉽고 빠르게 컴퓨터에서 템플릿을 실행하고 관리하실 수 있습니다.

### 1단계: Node.js 설치 (필수)
이 템플릿은 웹 기술로 빌드되므로, 실행을 위해 Node.js 환경이 필요합니다.
1. [Node.js 공식 홈페이지 (https://nodejs.org/ko)](https://nodejs.org/ko)로 접속합니다.
2. 메인 화면에 크게 표시된 **LTS** (안정화 버전) 다운로드 버튼을 클릭하여 설치 파일을 받습니다.
3. 다운로드된 설치 프로그램을 실행하고, 기본 설정을 유지한 채 'Next'를 눌러 설치를 완료해 주세요.

### 2단계: 프로젝트 내 컴퓨터로 가져오기 (택 1)

초보자분들이 프로젝트를 내 컴퓨터로 가져오는 방법은 크게 두 가지가 있습니다.

#### 방법 A: GitHub Desktop으로 안전하게 가져오기 (강력 추천 ⭐)
나중에 완성한 콘텐츠를 깃허브 저장소에 업로드하고 배포하려면 이 방법을 사용하는 것이 가장 편리합니다.
1. 이 저장소 페이지 우측 상단의 **`Use this template`** 버튼을 누르거나 **`Fork`** 버튼을 눌러 본인의 깃허브 계정으로 복제 저장소를 생성합니다.
2. [GitHub Desktop 홈페이지](https://desktop.github.com/)에서 앱을 다운로드하여 설치하고 로그인합니다.
3. 새로 생성한 본인의 깃허브 저장소 페이지에서 초록색 **`Code`** 버튼을 누른 뒤, **`Open with GitHub Desktop`**을 클릭합니다.
4. 저장할 내 컴퓨터 폴더 경로를 지정한 후 **`Clone`** 버튼을 누르면 다운로드가 완료됩니다.

#### 방법 B: ZIP 압축 파일로 빠르게 받아보기
버전 관리나 업로드 없이, 우선 로컬에서 단순 테스트만 빠르게 진행해보고 싶을 때 유용합니다.
1. 이 저장소 페이지 우측 상단의 초록색 **`Code`** 버튼을 클릭합니다.
2. 메뉴 맨 아래에 있는 **`Download ZIP`**을 클릭하여 프로젝트 전체를 다운로드합니다.
3. 다운로드한 ZIP 파일의 압축을 원하시는 폴더 위치에 풀어줍니다.

### 3단계: 더블클릭하여 실행하기
> [!TIP]
> 복잡한 터미널 명령어를 일일이 입력하지 않아도 되도록 템플릿 내부에 윈도우 전용 원클릭 실행 스크립트들이 준비되어 있습니다.
> - **[개발 서버 실행.cmd](file:///c:/Users/kgm20/Desktop/바탕 화면/창작/쵸아 템플릿1/개발 서버 실행.cmd)**: 더블클릭 한 번으로 구동에 필요한 라이브러리를 자동 설치하고 곧바로 로컬 개발 서버를 오픈합니다.
> - **[빌드 확인.cmd](file:///c:/Users/kgm20/Desktop/바탕 화면/창작/쵸아 템플릿1/빌드 확인.cmd)**: 배포용 압축/최적화 결과물이 오류 없이 잘 생성되는지 검증합니다.

1. 가져온 프로젝트 폴더(압축 푼 곳 또는 클론한 곳)로 이동합니다.
2. **`개발 서버 실행.cmd`** 파일을 더블클릭하여 구동합니다.
3. 최초 실행 시에는 구동 라이브러리(`node_modules`)를 자동으로 다운로드 및 설치하므로 10~30초가량 대기 시간이 필요합니다.
4. 설치 및 실행이 정상적으로 완료되면 자동으로 인터넷 브라우저 창이 열리며 로컬 테스트 화면(`http://localhost:5173`)이 나타납니다.
5. 테스트를 마치려면 켜져 있는 검은색 프롬프트 창을 그냥 닫아주시면 됩니다.

## 디렉토리 구조 (Folder Structure)

```text
src/
├── components/          # 주요 UI 및 화면 컴포넌트
│   ├── Intro/           # 인트로/시작 화면
│   ├── Story/           # 컷신(비주얼 노벨) 연출 화면
│   ├── WorldSetup/      # 시작 프로필(이름, 테마) 입력 화면
│   ├── CYOABuilder/     # 본게임 빌더 핵심 컴포넌트
│   ├── RewardSelect/    # 보상/시나리오 선택 화면
│   └── CharacterSheet/  # 최종 캐릭터 빌드 리포트 시트
├── data/                # 콘텐츠 게임 데이터
│   ├── cutscenes/       # 컷신 단계별 대사 데이터 (cutsceneData.ts)
│   └── cyoa/            # 본게임 카드 섹션 데이터 (races.ts, index.ts)
├── hooks/               # Zustand 스토어 및 오디오/이미지 프리로더 훅
├── utils/               # 세이브/로드, 스탯 계산, 이명 생성 유틸리티
└── App.tsx              # 게임 페이즈 및 전체 흐름 제어 컴포넌트
```

#### 💬 방법 B: 웹 AI 챗봇(ChatGPT, Claude, Gemini 웹사이트) 사용하기
웹 브라우저를 통해 AI와 대화하며 코드를 받아와 직접 편집하는 방식입니다.

##### 1단계: AI에게 프로젝트 파일 구조 설명해주기
AI 채팅창에 작업을 요청하기 전에 아래의 파일 용도와 구조를 먼저 알려주어야 올바른 구문의 TypeScript 코드를 얻을 수 있습니다.
* **대화 및 연출 파일**: `src/data/cutscenes/cutsceneData.ts`
* **선택지 카드 데이터 파일**: `src/data/cyoa/races.ts`, `src/data/cyoa/faiths.ts`, `src/data/cyoa/body.ts`
* **섹션 탭 관리 파일**: `src/data/cyoa/index.ts`

##### 2단계: 아래 프롬프트 템플릿을 복사하여 웹 AI에게 물어보기
```text
내가 React + TypeScript 기반의 CYOA 게임 템플릿으로 나만의 게임을 만들고 있어.
여기에 맞춰서 콘텐츠 데이터 코드를 생성해 줘.

[나만의 게임 설정 및 스토리]
- 게임 테마: (예: SF 우주선 생존 모험)
- 스탯 종류: (예: 연료, 골드, 승무원 신뢰도)
- 인트로 대사 요약: (예: 경보음이 울리며 우주선이 외계 소행성과 충돌 위기임을 알리는 대사)
- 첫 번째 선택지 카드 종류: (예: 조종석으로 달려간다 - 연료 10 소모 / 구명정으로 대피한다 - 신뢰도 20 하락)

이 설정에 알맞은 스토리 대사 데이터를 작성해 주고, 기존의 `src/data/cutscenes/cutsceneData.ts`와 `src/data/cyoa/races.ts` 파일의 타입 구조 및 형식(interface)을 그대로 준수하여 덮어쓸 수 있는 전체 TypeScript 코드를 생성해 줘.
```

##### 3단계: 전달받은 코드를 내 프로젝트 파일에 덮어쓰기
1. 웹 AI가 출력한 완성된 TypeScript 코드를 복사합니다.
2. 각각에 해당하는 파일(`cutsceneData.ts` 또는 `races.ts`)을 메모장이나 VS Code 같은 에디터로 열어줍니다.
3. 기존 내용을 전부 지우고 복사한 AI 코드를 붙여넣어 준 뒤 저장합니다.
4. **`개발 서버 실행.cmd`**를 실행해 내 스토리가 정상적으로 작동하는지 확인합니다!

### 🛠️ 개발자 디버그 모드 활용하기 (단축키 `F4`)

인트로(시작) 화면에서 키보드의 **`F4`** 키를 누르면 화면 우측 하단에 **[개발자 모드]** 버튼이 활성화됩니다.
- 이 버튼을 누르면 인트로 스토리, 본게임 빌더, 보상 선택, 캐릭터 시트, 엔딩 컷씬 등 원하는 게임 단계로 즉시 건너뛸 수 있는 이동 패널이 열립니다.
- 내가 제작 중인 콘텐츠의 특정 화면 연출이나 대사가 올바르게 표시되는지 빠르게 확인하고 싶을 때 매우 유용합니다.
