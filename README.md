# CYOA-template (쵸아 제작 템플릿)

이 레포지토리는 나만의 **CYOA (Choose Your Own Adventure)** 게임을 쉽고 세련되게 제작할 수 있도록 뼈대와 핵심 UI 기능만 남겨둔 React + TypeScript + Vite 기반의 템플릿입니다.

모바일 및 데스크톱 환경 모두에 호환되는 반응형 레이아웃, 동적 포인트/스탯 계산 시스템, 유려한 비주얼 노벨식 컷씬 모듈을 내장하고 있습니다.

---

## 주요 기능 (Features)

1. **인터랙티브 컷씬 시스템 (Story Screen)**
   - 비주얼 노벨 형식의 스토리 연출 지원.
   - 대사 길이에 맞춰 대화 상자 크기가 유동적으로 변하는 **가변형 대화 상자** (`height: auto`).
   - 대화창 본문 스크롤 시 대사 넘김 버그 방지 및 배경 클릭 시 정상 진행을 조율하는 **이벤트 투과(Pointer events) 처리**.
   - 대사 완성 후 선택지 버튼이 뾰로롱 나타나는 **딜레이 최적화** (기존 `0.6초` $\rightarrow$ `0.2초`로 단축).

2. **동적 빌더 시스템 (CYOA Builder)**
   - **단일 선택(Single-select)** 및 **다중 선택(Multi-select)** 카드 UI 제공.
   - 카드를 선택할 때마다 실시간으로 포인트 차감 및 캐릭터 스탯 가산/차감.
   - 특정 카드 획득 시 보너스 획득 알림(Toast) 제공.

3. **최종 빌드 요약 (Character Sheet)**
   - 플레이어가 설정한 이름, 선택한 테마, 스탯, 획득 태그 및 아이템/장비를 깔끔한 시트 형태로 요약.
   - 캐릭터 빌드 데이터 **JSON 파일 저장(Export) 및 불러오기(Import)** 기능 제공.

4. **오디오 시스템 (BGM & SFX)**
   - 단계별 BGM 전환 및 음량 설정이 가능한 플레이어 모달 탑재.

## 시작하기 (Getting Started)

깃허브나 개발이 처음이신 초보자분들도 아래의 3단계만 따라 하시면 1분 안에 컴퓨터에서 템플릿을 실행할 수 있습니다.

### 1단계: Node.js 설치 (필수)
컴퓨터에 웹 개발 도구를 구동하기 위해 필요합니다.
1. [Node.js 공식 홈페이지](https://nodejs.org/ko)로 접속합니다.
2. 화면에 보이는 **LTS** 버전(안정적인 최신 버전) 다운로드 버튼을 눌러 설치 파일을 다운로드하고 실행하여 설치를 완료합니다.

### 2단계: 템플릿 프로젝트 다운로드
1. 현재 이 깃허브 페이지 우측 상단에 있는 초록색 **`Code`** 버튼을 클릭합니다.
2. 아래에 나오는 메뉴 중 **`Download ZIP`**을 클릭하여 프로젝트를 다운로드합니다.
3. 다운로드한 ZIP 파일의 압축을 원하시는 폴더 위치에 풀어줍니다.

### 3단계: 더블클릭하여 실행하기
> [!TIP]
> 템플릿 내부에 윈도우용 실행 파일들이 내장되어 있어 복잡한 터미널 명령어를 일일이 입력하지 않아도 자동으로 실행됩니다.

1. 압축을 푼 프로젝트 폴더 안으로 들어갑니다.
2. 폴더 내부에 있는 **`개발 서버 실행.cmd`** 파일을 더블 클릭하여 실행합니다.
3. 처음 실행할 때 개발 서버 구동에 필요한 라이브러리 파일(`node_modules`)을 자동으로 다운로드하여 설치하므로 잠시 기다립니다.
4. 설치가 완료되면 자동으로 인터넷 브라우저 창이 열리며 템플릿 실행 화면(`http://localhost:5173`)이 나타납니다.
5. 테스트가 끝나면 실행된 검은색 명령어 창을 닫아 종료하시면 됩니다.

---

### 개발자용 명령어 가이드 (Advanced)
터미널 환경에 익숙한 경우 직접 명령어를 입력하여 제어할 수 있습니다.

* **의존성 설치**: `npm install`
* **개발 서버 시작**: `npm run dev` (로컬에서 테스트 구동)
* **배포 파일 빌드**: `npm run build` (배포용 압축/최적화 결과물을 `dist` 폴더에 생성)

## 디렉토리 구조 (Folder Structure)

```text
src/
├── components/          # 주요 UI 및 화면 컴포넌트
│   ├── Intro/           # 인트로/시작 화면
│   ├── Story/           # 컷신(비주얼 노벨) 연출 화면
│   ├── WorldSetup/      # 시작 프로필(이름, 테마) 입력 화면
│   ├── CYOABuilder/     # 본게임 빌더 핵심 컴포넌트
│   ├── RewardSelect/    # 보상/시나리오 선택 화면
│   └── CharacterSheet/  # 최종 캐릭터 빌드 리포트 시트
├── data/                # 콘텐츠 게임 데이터
│   ├── cutscenes/       # 컷신 단계별 대사 데이터 (cutsceneData.ts)
│   └── cyoa/            # 본게임 카드 섹션 데이터 (races.ts, index.ts)
├── hooks/               # Zustand 스토어 및 오디오/이미지 프리로더 훅
├── utils/               # 세이브/로드, 스탯 계산, 이명 생성 유틸리티
└── App.tsx              # 게임 페이즈 및 전체 흐름 제어 컴포넌트
```

## 나만의 콘텐츠 추가하기

1. **컷신 대사 수정**: `src/data/cutscenes/cutsceneData.ts`의 문장과 이미지를 원하는 스토리로 변경하세요.
2. **본게임 선택지 수정**: `src/data/cyoa/races.ts`의 카드들을 지우고 원하는 카테고리(예: 직업, 특성, 동료, 위기 등)에 해당하는 스탯 가산과 비용(cost)을 작성하세요.
3. **새 섹션 등록**: 새로운 선택지 섹션 파일들을 만든 후, `src/data/cyoa/index.ts`의 `initialCYOAData.sections` 배열에 가져와 추가하기만 하면 자동으로 빌더에 탭과 카드가 등록됩니다.
